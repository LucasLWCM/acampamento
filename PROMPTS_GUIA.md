# 🚀 Guia de Prompts para Criação de Novas Páginas

Este arquivo foi preparado para servir de modelo. Sempre que você quiser que eu crie uma nova página para o seu site, basta copiar um dos modelos abaixo, ajustar os detalhes do seu produto/serviço e me enviar aqui no chat!

---

## 📋 Modelo 1: Página de Vendas (Sales Page / Landing Page)

> **Copie o texto abaixo e preencha os colchetes `[...]`:**

```text
Crie uma nova pasta chamada "[nome-do-produto]" e um arquivo `index.html` dentro dela, servindo como a nova página de vendas.

Detalhes da página:
- Produto/Serviço: [Ex: Curso de Psicologia / Mentoria / E-book]
- Público-Alvo: [Ex: Psicólogos, Pacientes, Jovens adultos]
- Promessa Principal: [Ex: Como aumentar o faturamento do seu consultório]
- Preço/Oferta: [Ex: R$ 497,00 ou 12x de R$ 49,70]

Seções desejadas:
1. Hero Section com Headline chamativa e botão CTA principal.
2. Vantagens / Benefícios em cards.
3. Para quem é / Para quem não é.
4. Depoimentos / Prova Social (cards de avaliação).
5. Tabela de Preço / Garantia de 7 dias.
6. FAQ em Accordion (Perguntas Frequentes).
```

---

## 📋 Modelo 2: Página de Captura (Lead Magnet / Squeeze Page)

```text
Crie uma nova pasta chamada "[nome-da-captura]" com um `index.html` dentro, para ser a nova página de captura.

Detalhes:
- Recompensa Grátis: [Ex: E-book Gratuito / Aula Grátis / Minicurso]
- Campos do Formulário: [Ex: Nome, E-mail, WhatsApp]
- Objetivo: Alta taxa de conversão com layout limpo e direto.
```

---

## 📋 Modelo 3: Página de Obrigado / Confirmação (Thank You Page)

```text
Crie uma nova pasta chamada "obrigado-[nome]" contendo o `index.html` dessa página de obrigado.

Detalhes:
- Ação concluída pelo usuário: [Ex: Inscrição confirmada / Compra efetuada]
- Próximos passos: [Ex: Entrar no grupo do WhatsApp, verificar o e-mail]
- Botão de Ação: [Ex: Entrar no Grupo VIP do WhatsApp]
```

---

## 💡 Dicas para obter os melhores resultados:
1. **Design System Integrado**: Todas as páginas criadas usarão automaticamente as variáveis de cores (`variables.css` ou `estoicismo.css`) e scripts.
2. **Novos Componentes**: Se você desejar uma funcionalidade específica (ex: contador regressivo, modal de checkout), basta solicitar no prompt!
